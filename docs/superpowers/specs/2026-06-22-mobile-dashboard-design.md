# 移动端 Dashboard 与全局导航设计

## 背景

v1.9.0 已为主要页面增加窄屏样式，但 Dashboard 仍沿用桌面信息结构：欢迎区、重复的开始面试入口、四张功能卡、三张状态卡和版本记录依次纵向堆叠。华为 Pura 80 Pro 真机能够触发窄屏样式，但首屏信息密度和操作层级仍不适合手机。

本次设计不通过 User-Agent、设备型号或物理像素判断终端。页面整体继续基于 CSS viewport 重排，组件根据实际可用宽度适配，触控能力只用于调整交互尺寸。

## 目标

- 手机首屏明确突出“开始模拟面试”。
- 常用页面可以通过稳定的底部导航进入。
- 减少大型卡片纵向堆叠，缩短 Dashboard 浏览路径。
- 覆盖手机竖屏、横屏、窄平板和桌面窄窗口。
- 不改变接口、数据库、Agent 流程和桌面端默认布局。

## 非目标

- 不重构现有前端路由体系。
- 不新增后端接口或 Dashboard 统计数据。
- 不使用 User-Agent sniffing 或维护设备型号列表。
- 不把面试聊天和 Coding 工作区改成底部导航页面。

## 移动端全局导航

登录后的普通功能页面显示固定底部导航：

1. 工作台：进入 Dashboard。
2. 开始面试：进入面试配置。
3. 历史记录：进入历史面试管理。
4. 个人中心：进入简历信息页面。

当前页面对应的导航项需要高亮。AI 总结从 Dashboard 快捷入口进入，不单独占用底部导航位置。

底部导航在登录页、加载页、面试聊天页和 Coding 工作区隐藏。主题切换、用户名和退出操作继续保留在顶部栏。桌面端不显示底部导航。

底部导航固定在 `safe-area-inset-bottom` 上方，页面内容增加等量底部空间，避免最后一项内容或按钮被遮挡。

## 移动端 Dashboard 信息结构

Dashboard 按以下顺序展示：

1. 紧凑顶部栏：产品名称、主题切换和用户状态。
2. 欢迎信息：展示最近一次面试的方向和状态；无记录时显示首次使用提示。
3. 主操作卡：只保留一个“开始新的模拟面试”入口。
4. 训练概览：横向展示累计面试、已完成和累计消息。
5. 快捷入口：展示简历信息和 AI 总结。
6. 最近更新：默认展示当前版本和最新一条摘要，点击后在 Dashboard 内展开现有横向版本列表，不新增页面或路由。
7. 固定底部导航。

现有 Dashboard 主操作卡与第一张功能卡语义重复，移动端只保留主操作卡。历史记录和开始面试已由底部导航承载，不再重复显示为大型快捷卡。

如果现有数据能够确定存在可继续的中断面试，则在主操作卡中提供“继续面试”次级入口；如果当前数据不足以可靠判断，则不增加推断逻辑，保持只有“开始面试”。

## 桌面与平板布局

- `<= 640px`：完整移动端 Dashboard 和固定底部导航。
- `641px–960px`：紧凑平板布局，避免只做单栏化后继续保留桌面尺寸卡片。
- `> 960px`：保留当前桌面 Dashboard 和顶部导航。

断点用于控制页面级结构。Dashboard 概览、快捷入口和版本摘要应优先使用弹性 Grid/Flex；组件需要根据自身空间变化时使用 Container Query，不依赖设备类别。

触控设备可通过 `(pointer: coarse)` 增大点击区域，但不能因此切换页面结构。高度敏感区域使用 `dvh` 或 `svh`，并保留安全区域内边距。

## 数据与错误状态

- 继续复用 `fetchInterviewSessions()` 及当前统计计算，不新增请求。
- 历史概览加载失败时，训练概览显示“暂不可用”。
- 历史请求失败不能阻止用户开始新面试或使用其他入口。
- 无历史记录时，最近面试区域显示明确空状态。
- 长用户名、长方向名称和系统大字号下允许换行或省略，不得产生页面级横向滚动。

## 可访问性

- 底部导航使用语义化导航元素，并提供可识别的标签和当前页状态。
- 图标不能作为唯一含义来源，每个入口保留短文字标签。
- 触控目标最小尺寸为 44×44 CSS px。
- 键盘焦点、主题颜色和禁用状态保持可见。
- 页面在 320 CSS px 宽度下不丢失信息和功能。

## 资源与安全影响

- 只增加少量 React 展示逻辑和 CSS，不增加服务端常驻资源。
- 不新增网络请求、第三方脚本、用户数据和本地持久化内容。
- 不改变认证、Cookie、用户数据访问边界和历史记录权限。
- Container Query 和媒体查询由浏览器执行，对当前小规模服务器没有额外压力。

## 验证标准

自动检查：

- `npm run lint`
- `npm run build`
- 现有前端测试
- CSS/DOM 横向溢出检查

浏览器视口：

- 手机：320、360、390、430 CSS px。
- 手机横屏：高度受限且宽度大于 640px 的场景。
- 平板：768、960 CSS px。
- 桌面：1280、1440 CSS px。

交互检查：

- 四个底部导航入口跳转正确，当前项高亮正确。
- 登录、面试聊天和 Coding 页面不显示底部导航。
- 主题切换、退出和历史容量提醒保持正常。
- 浏览器工具栏、底部安全区域和软键盘不遮挡主要操作。
- 手机页面没有非必要的双向滚动。
- 桌面 Dashboard 布局和交互没有回归。

最终需要在华为 Pura 80 Pro 真机上验证 Dashboard 竖屏、横屏、系统大字号和浏览器工具栏展开状态。
